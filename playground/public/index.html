Paste the before and after versions of a package-lock.json, pnpm-lock.yaml or yarn.lock. lockray shows what actually changed and flags lockfile injection, tampered packages, install scripts and typosquats.

Runs in your browser. Lockfiles are never uploaded; only package names go to the npm registry if you tick the box.
Run it on every pull request. Add the GitHub Action and lockray posts this review as a PR comment: 
- uses: actions/checkout@v4
- uses: yassinebounasser99/lockray@v0
Or from a terminal: npx github:yassinebounasser99/lockray
