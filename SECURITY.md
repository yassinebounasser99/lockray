# Security policy

lockray is a security tool, so bypasses matter. If you find a lockfile change that lockray should flag but doesn't, especially a way to hide a malicious package from it, please report it privately via [GitHub security advisories](https://github.com/yassinebounasser99/lockray/security/advisories/new) rather than a public issue.

Please include a minimal before/after lockfile pair that demonstrates the bypass. You'll get a response within a few days, and credit in the release notes if you'd like.
